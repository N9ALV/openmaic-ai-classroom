# OpenMAIC beginner quick guide

## Start here

1. With IQ Wealth's help, open **Start OpenMAIC.cmd** once.
2. Keep the one classroom window open.
3. On the home page, choose the large **Start learning** button.
4. Choose a lesson, read it and try **Check answers**.

The built-in library does not need an AI key or paid generation. Creating a new
AI classroom is a different activity and may use provider credit.

## Four useful controls

| What I want | What I use |
| --- | --- |
| Read a ready-made lesson | A numbered module in the Investment Learning Library; use Previous/Next to continue |
| Practise a calculation | Practice lab → Exercise |
| Check understanding | Select answers, then Check answers |
| Keep a lesson | Download PDF workbook, then find it in the browser's Downloads |

The PDF workbook opens in an ordinary PDF reader and has room for exercises,
sources and a separate answer section. An editable text download is also
available. A PowerPoint export and a complete interactive-classroom export are
separate.

## Continue later

After checking the three answers, choose **Mark lesson complete**. The library
and home screen offer **Continue learning**. This progress stays in this browser
on this device. Tick **Remember my answers on this device** only if you want quiz
answers and your written reflection retained. Use fictional examples.

**Export local progress** keeps a readable copy of the local record. **Reset
local progress** resets only the built-in learning record, after confirmation.
It does not clear the whole browser. Completion is practice, not a financial
qualification.

## Check sources

Each lesson has source links and a short evidence checklist. **Reviewer workspace**
is for someone carrying out an actual content review; leave it alone during an
ordinary learner demonstration. A link, an AI answer or a local approval label
is not proof of official approval.

## If something does not work

- **Page cannot be reached:** tell IQ Wealth. Do not open more classroom windows.
- **Saved classrooms missing:** do not assume they were deleted. Keep the
  original classroom tab open, do not clear browser data, and ask for help.
- **Generation requests a key or credit:** stop. Return to the built-in library
  unless we have deliberately agreed to set up AI generation.
- **Download missing:** check the browser's Downloads list with IQ Wealth.
- **Unsure what to press:** pause. Describe what you see; no need to guess.

## Before showing a client

Explain that this is an experimental educational pilot, with draft lessons and
hypothetical calculations—not personalised advice or an officially approved IU
course. Use fictional examples and follow your workplace's demonstration rules.

Never paste API keys, passwords or client account details into chat. Never
promise that AI output is correct just because it sounds confident.

**Remember:** a `localhost` address only refers to the computer using it. It is
not a link your boss or a client can use to see your saved work. Sharing needs
an approved exported file or hosted route, followed by an access check.
