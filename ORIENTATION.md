# Beginner orientation: use it, then explain it

## Our success criterion

The learner's workplace criterion is: **if I can use it myself, I can help other
beginners use it.** This session will test both independent use and clear
explanation, rather than just watching IQ Wealth operate the app.

Passing this orientation means readiness for a **supervised demonstration of
the tested pilot features**. It is not certification as a financial adviser,
approval of lesson content, or clearance to launch the app publicly.

## First session: approximately 25–35 minutes, at your pace

No preparation is needed. We can pause and resume using `ORIENTATION-PROGRESS.md`.
We will use fictional examples only. The first session needs no new AI key,
no provider payment and no AI lesson generation. Normal IQ Wealth usage is
separate from this promise about the classroom exercises.

IQ Wealth will give one action at a time, check what you see, then let you do
the next action. If something fails, we will investigate rather than ask you to
repeat the same restart or open more windows.

### 1. Open the right place

IQ Wealth will help you locate `Start OpenMAIC.cmd` in your OpenMAIC folder and
start it once, unless it is already running. Leave that one classroom window
open while using the app. We will bring the page into IQ Browser together.

There are two different experiences:

| Area | What it does | What it needs |
| --- | --- | --- |
| Built-in learning library | Ready-to-read lessons, self-checks, calculators and workbook downloads | The local app running; no AI key or generation charge |
| AI classroom builder | Creates a new classroom from your brief | A working model/provider; research for the investment briefs; usage may cost money |

**Your check:** point to the library link and explain which area we are using.

### 2. Complete one short lesson

Open **Start learning**. Choose
**ASX foundations: ownership before action**.

Read the short sections, then answer its three self-check questions and choose
**Check answers**. Read the explanations, including any answer you want to revise.
This is practice, not an exam.

**Your check:** explain why the label “ETF” does not guarantee diversification.
Identify the editorial-draft notice and a source link. A source link is not proof
that every claim has been checked today.

### 3. Use the practice lab

Select **Loss and recovery**. Try a loss of 20%, then 50%.

**Your check:** explain why a 20% loss needs a 25% gain to recover, and a 50%
loss needs a 100% gain. The percentages use different starting balances. This
arithmetic is not a forecast of whether or when recovery will happen.

We can also try the currency or fee exercise if time permits. All starting
values are hypothetical. Never enter a client's private account details.

### 4. Save something and find it again

Return to the ASX foundations lesson and choose **Download PDF workbook**.
We will open the browser's Downloads list, locate the actual file and have
IQ Wealth help you read it if needed. The workbook is a printable PDF, not a
PowerPoint or the complete interactive classroom.

**Your check:** find the downloaded file again and explain the difference
between saving a file and sharing access to it.

The local classroom address is not a shareable client link. An exported file
needs an approved sharing route and verified recipient access. Do not send a
link merely because it looks plausible.

### 5. Explain it back as if I were a client

You guide IQ Wealth through a three-minute demonstration. IQ Wealth takes the
role of a new client and asks:

1. Where do I start without paying for AI generation?
2. How do I check my understanding?
3. Where did my workbook go?
4. Can I treat this draft as personalised investment advice?
5. What should I do if saved classrooms do not appear?

You may use `BEGINNER-QUICK-GUIDE.md`. We will repeat one task with fewer prompts
so you have practical confidence, rather than a tick based on assistance alone.

## What is safe to demonstrate in this phase?

- The built-in draft library, self-checks, calculators and workbook download.
- The difference between a draft, a checked source and approved content.
- How to pause, ask for help and avoid destructive troubleshooting.
- IU's Discover → Educate → Evaluate → Perform idea as a way to organise
  learning and decisions, not a reason to rush into a transaction.

The pilot material is informed by IU context but is not an official IU course.
An internal demonstration is not approval to distribute it as client education.
Follow the workplace's content, permission and client-support rules.

## A later phase: AI classroom creation

This is separate and will only start after we deliberately confirm:

- which account/provider/model will be used;
- a spending limit or explicitly verified free option;
- replacement of keys previously disclosed in chat;
- research availability and what happens when research fails;
- a fictional, non-sensitive lesson brief;
- content review, export and recipient-access checks.

We will not ask you to paste a key into chat. Reading the built-in library does
not prove that live generation, narration, interactive exports or a hosted
multi-user deployment are ready.

## Facilitator notes for IQ Wealth

1. Read `ORIENTATION-PROGRESS.md` first. Record what was observed, not assumed.
2. Ask whether the learner wants to continue with the planned first session;
   keep timings flexible and avoid a long technical introduction.
3. Check current app/browser state before issuing startup instructions. Load
   the current IQ Browser usage guidance when using browser controls.
4. Preserve the original `http://localhost:3000` browser origin and IQ Browser
   profile. The launcher may open the Windows default browser, not IQ Browser.
   Do not silently switch ports, addresses or profiles to find old classrooms.
5. Current launch target: `C:\Users\CMD\OneDrive\Documents\OpenMAIC\Start OpenMAIC.cmd`.
   Library target after startup: `http://localhost:3000/learn`.
6. Existing tests establish technical readiness for the library, not this
   learner's competence. Ask them to perform the key actions and teach them back.
7. If a workbook cannot be opened by Windows, help read the actual downloaded
    file in IQ Wealth; do not install software or upload it externally by default.
8. If storage is unavailable, keep existing tabs and exports. Use the tested
   non-destructive retry first. Never clear browser data as a routine fix.
9. No key screens, live generation, payment, publication, client data, trades or
   GitHub changes are part of the first session.
10. Update the progress record at a pause or completion. Mark a task independent
    only after the learner completes it without step-by-step prompting.
